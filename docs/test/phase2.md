## B. PC のブラウザで確かめること

5173 番はほかで使っている可能性があるので、別の番号で立てる。確かめたら必ず止める。

```sh
npm run build && npx vite preview --port 4192 --strictPort --host 127.0.0.1   # → http://127.0.0.1:4192/oyasumi-memo/app/
```
- Windows で `npx` を止めても node が残ることがある。止めたあと `Get-NetTCPConnection -State Listen -LocalPort 4192` で何も出ないことを確かめる（今回も残っていたので止めた）
- 保存の失敗は、アプリのコードを変えずに、ページの中で JavaScript を実行して IndexedDB の書き込みを失敗させる（開発者ツールのコンソールに貼る）：
  ```js
  const P = IDBObjectStore.prototype; const orig = { add: P.add, put: P.put };
  P.add = P.put = function () { throw new DOMException('test', 'QuotaExceededError'); };
  // 確かめたら戻す：P.add = orig.add; P.put = orig.put;
  ```
  （`IDBDatabase.prototype.transaction` を差し替える方法では失敗しなかった。Dexie がそこを通らないため）
- IndexedDB の中身は、同じページで `indexedDB.open('oyasumi-memo')` から `entries` を読んで見た

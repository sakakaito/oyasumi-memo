## B. PC のブラウザで確かめること

5173 番はほかで使っている可能性があるので、別の番号で立てる。確かめたら必ず止める。

```sh
npx vite --port 5191 --strictPort --host 127.0.0.1           # 開発用 → http://127.0.0.1:5191/oyasumi-memo/app/
npm run build && npx vite preview --port 4191 --strictPort --host 127.0.0.1   # 公開と同じ中身 → http://127.0.0.1:4191/oyasumi-memo/
```
- Windows で `npx` を止めても node が残ることがある。止めたあと `Get-NetTCPConnection -State Listen -LocalPort 5191,4191` で何も出ないことを確かめる（今回も残っていたので止めた）

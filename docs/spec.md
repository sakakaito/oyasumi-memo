# 開発指示書：寝る前の「頭の荷下ろし」アプリ（仮称：おやすみメモ）

> この指示書は Claude Code に渡して、構成づくりから実装まで進めるためのものです。
> 実装は下記「フェーズ」の順に進め、各フェーズ完了時に動作確認の手順を提示してから次に進んでください。

---

## 1. プロダクト概要

- **目的**：寝る前に頭の中の考えごとを声で吐き出し、「預けた」安心感で眠りにつけるようにする
- **コンセプト**：書く・見返すためのメモではなく、**手放すためのメモ**
- **想定ユーザー**：布団に入ってから考えごとで眠れない人
- **提供形態**：無料のPWA（ホーム画面に追加できるWebアプリ）
- **運用コスト目標**：0円（サーバー・有料APIを使わない）

### やること（スコープ内）
- 声（またはテキスト）での吹き込み
- 簡易ルールによる自動仕分け
- 朝に一覧で振り返る画面
- 端末内へのデータ保存

### やらないこと（スコープ外・今回は実装しない）
- ユーザー登録・ログイン
- サーバー側のデータ保存・同期
- AI API（OpenAI / Claude 等）による処理
- 課金機能
- プッシュ通知（将来対応）

## 2. 技術スタック

| 項目 | 採用技術 | 理由 |
|---|---|---|
| ビルド | Vite | 軽量・高速 |
| 言語 | TypeScript | 保守性 |
| UI | React | 実装しやすさ |
| スタイル | CSS Modules または素のCSS（CSS変数でテーマ管理） | 依存を減らす |
| 保存 | IndexedDB（Dexie.js 経由） | 端末内保存・容量に余裕 |
| 音声入力 | Web Speech API（`SpeechRecognition` / `webkitSpeechRecognition`） | 無料 |
| PWA | vite-plugin-pwa | manifest / Service Worker 自動生成 |
| テスト | Vitest | 仕分けロジックの単体テスト |
| デプロイ | Cloudflare Pages / Vercel / GitHub Pages のいずれか（無料枠） | 0円運用 |

### 音声入力の注意点
- Web Speech API は端末・ブラウザで対応状況が異なる。**非対応時はテキスト入力欄にフォールバック**すること
- iPhone ではキーボードのマイクボタン（音声入力）でも入力できるため、テキスト欄は常に使える状態にする
- 言語は `ja-JP` 固定

## 4. データモデル

```ts
type Category = 'todo' | 'worry' | 'idea' | 'other';

interface Memo {
  id: string;            // uuid
  text: string;          // 吹き込んだ内容
  category: Category;    // 自動仕分け結果（後からユーザーが変更可）
  createdAt: number;     // UNIXミリ秒
  sleepDate: string;     // その夜の日付 'YYYY-MM-DD'（深夜0〜5時は前日扱い）
  done: boolean;         // 朝に「完了/片付けた」チェック
  archived: boolean;     // 見終わったもの
}
```

- `sleepDate` は「その夜」単位でまとめるためのキー。**0:00〜4:59 の入力は前日の日付**にする
- データはすべて IndexedDB に保存し、外部送信は一切しない

## 5. 画面仕様

### 5-1. 夜モード（吹き込み画面）※最重要
**とにかく刺激を減らす。目が冴えないことを最優先。**

- 背景はほぼ黒（例：`#0b0b0f`）、文字は暗めのグレー（例：`#6b6b76`）
- 白・青系の強い色、アニメーション、点滅は使わない
- 画面中央に大きな録音ボタン1つ（タップで開始/停止）
- 認識中のテキストは小さく薄く表示（読ませない）
- 停止後、「預かりました」と一言だけ表示して2秒後にフェードアウト
- 追加で吹き込みたい場合はそのままボタンを再タップ
- 下部に小さく「テキストで入力」リンク（フォールバック用）
- 画面上に余計な情報（件数、時計、ナビゲーション）は出さない

### 5-2. 朝モード（振り返り画面）
- 背景は明るめで読みやすく
- 前夜（直近の `sleepDate`）のメモをカテゴリ別に表示
  - 「やること」「気になること」「アイデア」「その他」
- 各メモで：カテゴリ変更（タップで切替）、完了チェック、削除
- 「全部見た」ボタンで一括アーカイブ
- 過去の夜の一覧（日付ごと）も見られるようにする

### 5-3. 設定
- 夜モード/朝モードの自動切替時刻（初期値：18:00〜翌4:59 を夜）
- 手動でモード切替
- データのエクスポート（JSON / テキスト）
- 全データ削除（確認ダイアログあり）
- 「データは端末内にのみ保存され、外部に送信されません」の明記

### 5-4. モード自動切替
- 起動時刻で夜/朝を判定して初期画面を決める
- 画面右上に小さく切替アイコン（夜モードでは目立たせない）

## 6. 仕分けロジック（AIなし・ルールベース）

`src/lib/classify.ts` に実装。キーワード辞書でスコアリングし、最も高いカテゴリを採用。該当なしは `other`。

| カテゴリ | キーワード例 |
|---|---|
| todo（やること） | 明日, あした, やる, しないと, しなきゃ, 連絡, 電話, メール, 買う, 提出, 予約, 締め切り, 忘れずに |
| worry（気になること） | 不安, 心配, 気になる, どうしよう, 大丈夫かな, 嫌だ, 怒られ, 失敗, モヤモヤ |
| idea（アイデア） | 思いついた, アイデア, いいかも, やってみたい, 作りたい, 企画, ネタ |

- 辞書は別ファイル（`keywords.ts`）に分離し、後から追加しやすくする
- 1回の吹き込みに複数の内容が含まれる場合に備え、「。」「それと」「あと」などで分割して個別に仕分ける
- `tests/classify.test.ts` に代表例を10件以上用意して単体テストする

## 7. PWA要件

- `manifest`：アプリ名、短縮名、テーマ色（暗色）、`display: standalone`、アイコン各種
- Service Worker でオフライン動作（初回読み込み後は通信なしで使える）
- iOS 向けに `apple-touch-icon` と `apple-mobile-web-app-*` メタタグを設定
- ホーム画面追加を促す案内を、朝モードの初回のみ表示

---

## 8. 非機能要件

- **プライバシー**：外部通信なし（アナリティクスも入れない）
- **パフォーマンス**：初回表示 2 秒以内（モバイル回線想定）
- **アクセシビリティ**：ボタンに `aria-label`、文字サイズは最小 16px
- **対応環境**：iOS Safari / Android Chrome の最新版を優先

#### SEO（狙う検索語）
Ahrefs で日本の月間検索数を調べた結果（2026-10-24 時点）。

| 検索語 | 月間検索数 | KD | スマホ比率 |
|---|---|---|---|

| ブレインダンプ | 1,200 | 0 | 71% |
| 不安で眠れない | 1,100 | 0 | 96% |
| 考え事 眠れない | 800 | 0 | 97% |
| ジャーナリング アプリ | 600 | 0 | 86% |

- 軸にする検索語：**「考え事 眠れない」「考えすぎて眠れない」**。補助として「ブレインダンプ」

- スマホ比率 97% → **布団の中で今まさに眠れずにいる人**が検索してくる
- 心の健康に関わる領域なので、治療効果をうたう表現は避ける。紹介ページに「眠れない日が続く場合は医療機関へ」の一言と相談窓口へのリンクを置く

## 13. 未決事項（議論中）

### 先に確かめること：iPhone 実機での音声入力の試作
試作ページ：`prototype/voice-test/`（公開 URL は README を参照）

音声入力を2通り（Web Speech API／iOS キーボードの音声入力）載せた1枚の試作ページで、次を確かめる。

| 確かめること | 駄目だった場合 |
|---|---|
| Safari のタブで Web Speech API が動くか | キーボードの音声入力を本命にする |
| ホーム画面に追加したアプリで動くか | 同上（音声を主にする方針は変えない） |
| マイクの許可を毎回聞かれないか（**最重要**） | 毎晩白いダイアログが出るのは致命的。入り口を見直す |
| 無音になったら何秒で認識が止まるか | 自動保存の作り方が変わる |
| 小声でどれくらい認識できるか | テキスト入力の重みが変わる |
| 暗い画面（`color-scheme: dark`）でキーボードも暗くなるか | テキスト入力欄の見た目を調整する |

### 音声入力の体験
- 寝落ち対策の無音時間（試作は 10 秒）は、実機の結果を見て決める
- 録音中の表示：ボタンの色がほんの少し明るくなるだけ（動かさない）。認識した文字はごく薄く
- 誤認識は朝の画面でタップして直す
- 1回の吹き込みは、文字ではなく**認識結果の区切り（話して間が空いたところ）ごと**に1件のメモにする（日本語の認識結果には「。」がほぼ付かないため）

### 提案中のアイデア（採否未定）
- A. 朝に「完了」と「手放す」を分ける（「気になること」は「まだ気になる？ → もう大丈夫／今日考える」）
- B. 吹き込み後の「おやすみ」ボタンで画面を真っ黒にして終える
- C. 夜モードの色を暖色寄りに（例：文字 `#7a6a58`）
- D. 研究（Scullin ら 2018：寝る前に明日やることを5分書くと寝付きが早くなった）を紹介ページで触れる
- E. 終わらなかった「やること」を次の夜に持ち越すか
- F. 紹介ページとアプリを一体にする（検索から開いたページがそのまま夜モードで、その場で吐き出せる）
  - 注意：iPhone では Safari のデータはホーム画面アプリに引き継がれない。移行方法を決める必要がある
- I. 朝の振り返りは通勤中に片手で 30 秒、を想定した画面にする

### 技術面で決めること
- 本番の公開先：GitHub Pages か Cloudflare Pages か、独自ドメインを持つか（運用コスト 0 円の目標とのかね合い）
- `sleepDate` の境目と夜モードの時刻は同じ設定値から計算する
- `classify()` は将来 AI 版に差し替えられるよう、最初から非同期（Promise を返す形）にする
- `navigator.storage.persist()` で保存データを消されにくくする
- マイクの許可は夜ではなく、最初の案内か朝モードで取る

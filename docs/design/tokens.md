# デザイントークン案（初版）

- 作成：2026-10-25／UX/UI デザイナー役
- 状態：**案**（オーナー確認待ち。色の最終決定は iPhone 実機で、画面の明るさを一番下げた状態で見てから）
- 出発点：試作 `prototype/voice-test/` の色（背景 `#0b0b0f`、文字 `#7a6a58`）
- コントラスト比はすべて WCAG 2.x の計算式で算出した値（小数第 2 位まで）

---

## 1. 夜の暗さとコントラストの両立の考え方

夜の画面は「目が冴えない」ことが最優先（spec §5-1）。一方で、エラー時の直し方や入力した文字は**読めないと困る**。そこで、文字を「読ませるもの」と「読ませないもの」に分け、明るさに**下限と上限**の両方を決める。

| 種類 | 例 | 目標 | 使うトークン |
|---|---|---|---|
| 読む文字 | 案内文、エラーの直し方、入力欄の文字、ボタンの文字 | **4.5:1 以上**（WCAG AA） | `--n-text` |
| 大きい文字・アイコン | 録音ボタンの文字（20px・太字）、朝への切替アイコン、見出し | **3:1 以上**（大きい文字・文字以外の UI の基準） | `--n-text-sub` |
| 読ませない文字 | 認識中の文字、「おやすみなさい」の消えていく文字 | **あえて 2:1 未満**。中身は朝に十分なコントラストで読める | `--n-text-faint` |
| 明るさの上限 | 夜の画面のすべての色 | 背景に対して**約 5.5:1 を超えない**。白・青系は使わない | – |

- 階層は色の明るさの差ではなく、**文字の大きさ・太さ・余白**で作る（暗い画面で薄い灰色を何段も使うと、下の段が読めなくなるため）
- 「読ませない文字」は WCAG の例外ではない。そのため読み上げでは中身を流さず（`aria-live="off"`）、保存後に「預かりました」だけを伝える。読みたい人は朝の画面で読める
- 試作の文字色 `#7a6a58` は背景に対して **3.77:1** で、読む文字の基準 4.5:1 に届かない。読む文字は `#917e68`（5.04:1）に少しだけ上げ、`#7a6a58` に近い暗さは大きい文字用（`--n-text-sub`）に回す案（→ `flow.md` §6 オーナーに決めてほしいこと 2）
- ほかに効くこと
  - `<meta name="color-scheme" content="dark">` と `theme-color` を暗色にして、キーボードやステータスバーも暗くする（iPhone で実際に暗くなるかは §13 の確認項目）
  - 2026-10-26 フェーズ2で更新：meta に加えて CSS でも `:root { color-scheme: dark }`（夜・紹介）／`:root[data-mode="morning"] { color-scheme: light }`、夜の入力欄にも `color-scheme: dark` を置く。`light dark` にはしない（ライトモードの iPhone で白いキーボードになる）。入力欄の配色は `screens.md` 0-3。新しいトークンは足していない
  - 夜の画面に `#fff` や青を使わない。フォーカス枠も暖色の `--n-text`
  - 動きは「不透明度だけ」。位置・大きさが動くもの、点滅、回転は使わない

## 2. 夜（night）のトークン

```css
:root[data-mode="night"] {
  /* 背景 */
  --n-bg:         #0b0b0f;  /* 画面の背景（試作と同じ） */
  --n-surface:    #141117;  /* ボタン・入力欄の地 */
  --n-surface-2:  #1b171b;  /* 下から出るシート（文字で書く・エラー） */
  --n-rec-on:     #2b241e;  /* 録音中のボタン。ほんの少し明るくなるだけ */
  --n-black:      #000000;  /* 「おやすみ」画面 */
  --n-line:       #3a3230;  /* 区切り線・枠（飾り。意味は文字で伝える） */

  /* 文字 */
  --n-text:       #917e68;  /* 読む文字 */
  --n-text-sub:   #73644f;  /* 大きい文字・アイコン */
  --n-text-faint: #3d352d;  /* 読ませない文字（認識中） */
  --n-warn:       #a07f4c;  /* エラーの枠と見出し */
  --n-focus:      #917e68;  /* キーボード操作時のフォーカス枠 */
}
```

| 文字の色 | `--n-bg` | `--n-surface` | `--n-surface-2` | `--n-rec-on` | 判定 |
|---|---|---|---|---|---|
| `--n-text` #917e68 | 5.04 | 4.80 | 4.55 | 3.92 | どの地でも読む文字 4.5 以上。録音中ボタンの上は大きい文字なので 3 以上で可 |
| `--n-text-sub` #73644f | 3.43 | 3.27 | 3.09 | 2.67 | 大きい文字・アイコン用。**録音中ボタンの上では使わない** |
| `--n-text-faint` #3d352d | 1.63 | 1.56 | 1.47 | – | 読ませない文字だけ |
| `--n-warn` #a07f4c | 5.27 | 5.02 | 4.76 | – | エラーの見出しにも使える |
| （参考）試作 #7a6a58 | 3.77 | 3.59 | – | 2.93 | 読む文字には足りない |

- 明るさの上限：いちばん明るい `--n-warn` でも 5.27:1。上限 約 5.5:1 の中に収まる

## 3. 朝（morning）のトークン

通勤中に片手 30 秒で見る想定（§13 案I）。屋外・電車でも読めるよう、コントラストは高く、ただし真っ白は避けて暖かい生成り色にする。

```css
:root[data-mode="morning"] {
  --m-bg:          #f6f2ea;  /* 画面の背景（生成り） */
  --m-surface:     #fffdf8;  /* カード */
  --m-line:        #ddd3c6;  /* 区切り線（飾り） */
  --m-control:     #857868;  /* 入力欄・チェックの枠（3:1 以上が必要な UI） */

  --m-text:        #2b2622;  /* 本文 */
  --m-text-sub:    #5f554c;  /* 時刻・補足 */
  --m-primary:     #6b4a2b;  /* 主ボタン（「全部見た」） */
  --m-on-primary:  #fffdf8;  /* 主ボタンの文字 */
  --m-danger:      #8f3324;  /* 削除・全部消す */
  --m-focus:       #6b4a2b;

  /* 分類のしるし（色だけに頼らず、必ず文字を添える） */
  --m-todo-fg:  #5c3b1e;  --m-todo-bg:  #f3e6d6;  /* やること */
  --m-worry-fg: #4a3f5c;  --m-worry-bg: #ece8f1;  /* 気になること（赤は不安をあおるので避ける） */
  --m-idea-fg:  #2f4a3a;  --m-idea-bg:  #e2ece4;  /* アイデア */
  --m-other-fg: #4a4038;  --m-other-bg: #ebe5dc;  /* その他 */
}
```

| 組み合わせ | 比 |
|---|---|
| `--m-text` / `--m-bg`・`--m-surface` | 13.40 / 14.72 |
| `--m-text-sub` / `--m-bg`・`--m-surface` | 6.51 / 7.15 |
| `--m-control` / `--m-bg`・`--m-surface` | 3.85 / 4.23（枠の基準 3:1 以上） |
| `--m-on-primary` / `--m-primary` | 7.83 |
| `--m-danger` / `--m-bg` | 7.05 |
| 分類のしるし（文字 / 地） | やること 8.15・気になること 8.06・アイデア 8.03・その他 8.06 |

## 4. 紹介ページ（intro）

検索から来る人の 97% はスマホで、多くは布団の中と考えられる（backlog US-50）。紹介ページは**夜のトークンをそのまま使う**。長い文を読ませるので、本文だけ 1 段明るい色を許す。

```css
:root[data-mode="intro"] {
  /* 夜のトークンを継承し、次だけ足す */
  --i-text-read: #9a8770;  /* 本文（背景に対して 5.68:1。上限 約 5.5 をわずかに超えるが、長文を読むための例外） */
}
```

## 5. 共通のトークン（夜・朝・紹介で同じ）

```css
:root {
  /* 文字 */
  --font: -apple-system, "Hiragino Sans", "Hiragino Kaku Gothic ProN", "Noto Sans JP", system-ui, sans-serif;
  --fs-min:     16px;  /* これより小さい文字は使わない（spec §8）。入力欄も 16px 以上（iPhone で勝手に拡大されない） */
  --fs-body:    17px;  /* 本文・メモのカード */
  --fs-lead:    18px;  /* 夜の見出し・朝の分類名 */
  --fs-rec:     20px;  /* 録音ボタンの文字（太さ 600 で「大きい文字」扱い） */
  --fs-title:   22px;  /* 朝の日付見出し */
  --fs-display: 28px;  /* 紹介ページの h1 */
  --lh-body:    1.7;
  --lh-title:   1.4;
  --fw-normal:  400;
  --fw-medium:  500;
  --fw-strong:  600;   /* 夜は 700 を使わない（太すぎる文字は明るく見える） */

  /* 余白（4 の倍数） */
  --sp-1: 4px;  --sp-2: 8px;  --sp-3: 12px; --sp-4: 16px;
  --sp-5: 24px; --sp-6: 32px; --sp-7: 48px; --sp-8: 64px;
  --gutter: 16px;  /* 画面の左右。これに env(safe-area-inset-*) を足す */
  --max-w: 560px;  /* タブレット・PC での最大幅 */

  /* タップ領域 */
  --tap-min: 44px;   /* これより小さくしない（spec §8 の考え方、Apple の目安） */
  --tap:     48px;   /* ふつうのボタン */
  --tap-gap: 8px;    /* となりのタップ領域との最小の間 */
  --rec-size: 184px; /* 録音ボタンの直径。375px 幅でも左右に 80px 以上空く */

  /* 角丸 */
  --r-s: 8px; --r-m: 12px; --r-l: 20px; --r-full: 999px;

  /* 動き */
  --fade-status: 1000ms;  /* 「預かりました」が消えるまでのフェード（表示 2 秒のあと） */
  --t-quick:     150ms;   /* 朝の画面のみ。夜は不透明度と背景色の変化だけに使う */
}

@media (prefers-reduced-motion: reduce) {
  :root { --fade-status: 0ms; --t-quick: 0ms; }
}
```

### 使い方の決まり
- 夜と朝の切り替えは `<html data-mode="night|morning|intro">` で行う。コンポーネントは `--n-*`／`--m-*` を直接使わず、役割の名前（`--bg`・`--text`・`--surface` など）に読み替えた変数を使うと、同じ部品を夜にも朝にも置ける（エンジニアの判断でよい）
- 文字サイズは `--fs-min` 未満を作らない。試作にある 13px のタグ・ログは本番では使わない
- タップできるものは、見た目が小さくても当たり判定を `--tap-min` 四方以上にする（例：朝への切替アイコンは 24px の絵に 44px の当たり判定）

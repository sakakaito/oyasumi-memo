## 0. 共通の部品

### 0-1. 話すボタン（S1・S2 の中央）
方式W・方式K のどちらでも同じ見た目・同じ文言で置ける部品。押したあとのふるまいだけが違う。

| | 方式W（Web Speech API） | 方式K（キーボードの音声入力） |
|---|---|---|
| 見た目 | 直径 184px の丸。地 `--n-surface`、文字「タップして話す」20px・太さ 600 | 同じ |
| タップすると | その場で録音を始める（下の「録音中」） | S4 が開き、入力欄にカーソルが入ってキーボードが出る |
| 止め方 | もう一度タップ／無音が続いたら自動（考えごと 10 秒・日記 20 秒、試作値） | 「預ける」／文字が増えなくなって同じ時間がたったら自動 |
| `aria-label` | 待機中「話して預ける」（S1 は「日記を話す」）／録音中「止めて預ける」（S1 は「止めて日記に残す」） | 「入力欄を開く」 |
| `aria-pressed` | 録音中は `true` | 使わない |

- 実装の注意（方式K）：iPhone でキーボードを出すには、タップの処理の中で入力欄に `focus()` する必要がある
- 環境で方式を使い分ける場合（例：Safari のタブは W、ホーム画面アプリは K）も、利用者が方式を選ぶ画面は作らない。使えない方を出さないだけにする

### 0-2. 状態の表示行（話すボタンの下、高さ固定）
- 1 行ぶんの高さを常に確保して、文字が出ても消えてもボタンの位置が動かないようにする
- 認識中の文字：`--n-text-faint`・16px・2 行まで（はみ出したら古い方を隠す）・`aria-live="off"`
- 保存の知らせ：`--n-text`・16px・`role="status"`。2 秒表示して 1 秒かけて消える

### 0-3. 文字で書くシート（S4）
S1・S2 の下から出る。方式K のときは話すボタンからも、ここが開く。

| 要素 | 文言 | 備考 |
|---|---|---|
| 見出し | S2 から：「文字で預ける」／S1 から：「文字で日記を書く」 | 18px |
| 入力欄 | 案内（プレースホルダー）：「思いついた順に、そのままどうぞ」 | 17px・地 `--n-surface`・最低 5 行。`aria-label`「預けたいこと」／「今日の日記」 |
| マイクの案内 | 「キーボードの マイク ボタンで、話して入力することもできます」 | 方式K では常に出す。方式W では出さない（文字で書きたい人のため） |
| 折りたたみ | 「マイクのボタンが出ないときは」→「設定 → 一般 → キーボード →『音声入力』をオンにしてください」 | 方式K のみ |
| 主ボタン | 「預ける」／「日記に残す」 | 右下、48px。入力が空のあいだは押せない（見た目は `--n-text-sub`） |
| 閉じる | 「閉じる」 | 左下。書きかけがあれば、閉じても下書きとして残す（次に開くと戻る） |

- 区切りの規則：S2 から送った文は、句点・改行・「それと」「あと」などで分けて複数のメモにする（US-01 方式K）。S1 から送った文は 1 つの日記
- 自動保存（方式K の寝落ち対策）：S2 は文字が増えなくなって 10 秒で保存してシートを閉じ「預かりました」。S1 は入力のたびに下書きを保存し、同じ日記に追記していく（日記が分かれない。US-10）

### 0-4. 夜のエラー表示（S1・S2）
白い画面・赤・点滅を使わない。話すボタンの下に、`--n-surface-2` の地と `--n-warn` の枠のカードで出す。`role="alert"`。

| 要素 | 文言・ふるまい |
|---|---|
| 見出し | エラーの種類ごとの一言（下の表） |
| 直し方 | 1〜2 文。iPhone の設定の場所は「→」でつなぐ |
| ボタン | ［文字で書く］（S4 を開く。1 タップで別の手段へ。US-06）／［閉じる］ |

| 原因（方式W のエラー名） | 見出し | 直し方 |
|---|---|---|
| `not-allowed` | マイクが許可されていません | アドレスバー左の「ぁあ」→ Web サイトの設定 → マイク を「許可」にしてから、もう一度タップしてください。 |
| `service-not-allowed`（Safari のタブ） | iPhone の音声入力が使えませんでした | 設定 → 一般 → キーボード →「音声入力」がオンか確かめてください。スクリーンタイムで Siri と音声入力が制限されていても使えません。 |
| `service-not-allowed`（ホーム画面アプリ） | この開き方では、声の入力が使えないようです | 「文字で書く」から、キーボードのマイクで話せます。 |
| `audio-capture` | マイクを使えませんでした | 通話中か、ほかのアプリがマイクを使っていないか確かめてください。 |
| `network` | 声を文字にできませんでした | 声を文字にするには通信が必要です。「文字で書く」なら、通信がなくても預けられます。 |
| `language-not-supported` | この端末では日本語の声の入力が使えませんでした | 「文字で書く」から、キーボードのマイクで話せます。 |
| 聞き取れなかった（`no-speech` など、保存したものが 0 件） | エラーのカードは出さない。状態の表示行に「聞き取れませんでした。もう一度タップしてください」 | – |
| 保存に失敗した（共通） | 保存できませんでした | 書いた文字は残してあります。もう一度「預ける」を押してください。（方式W のときは、認識した文字を S4 の入力欄に入れて開く。消さない。US-04） |

- 音声認識の機能が無い環境（`SpeechRecognition` が無い）はエラーにしない。最初から方式K としてふるまう
- 文言の出典：試作 v2 の `ERROR_HELP`。夜に読む長さに縮めた

## S0 紹介ページ（検索に出す唯一のページ）

### 狙う検索語と SEO の設定
- 軸：**「考え事 眠れない」**（月 800）・**「考えすぎて眠れない」**（月 200、上位ページへの流入 2,400）。補助：「ブレインダンプ」（月 1,200）。数値は spec §12（Ahrefs・2026-10-24）。デザイナーでは検索数を取り直していない（Ahrefs の今月の上限。§13）
- 題名・説明文はプロダクトオーナー案（backlog US-50）に合わせる

| 項目 | 案 |
|---|---|
| `<title>` | 考え事で眠れない夜に、頭の中を声で預けるメモ｜おやすみメモ |
| `h1`（1 つだけ） | 考えすぎて眠れない夜は、頭の中を声で預けて眠る |
| meta description | 考え事が頭から離れず眠れない夜に。布団の中で話すだけで、やること・気になることに分けて朝まで預かります。登録不要・無料、メモは端末の中だけに保存。 |
| canonical・OGP の URL | 本番の公開先が決まってから（backlog「確認 3」） |
| OGP 画像 | 暗い地に月と「考え事で眠れない夜に」の画像（1200×630）。`og:image:alt` もつける |
| 構造化データ | `WebApplication`（名前・無料・対応環境）と、⑤がある場合の `FAQPage`。ページに無い内容は入れない |
| `<meta name="theme-color">` | `#0b0b0f` |

| 要素 | 文言・ふるまい |
